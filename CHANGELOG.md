# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-27

### Added
- Initial release of Uhasibu Prediction Market Platform
- Age verification system (18+)
- OTP-based authentication via Africa's Talking
- Bilingual support (English and Swahili)
- Virtual currency (vKES) system
- User profile management
- Market creation and trading functionality
- Admin dashboard for market management
- Docker Compose setup for easy deployment
- PostgreSQL database integration
- Nginx reverse proxy configuration
- Comprehensive README documentation
- Contributing guidelines
- Code of Conduct
- Security policy
- MIT License

### Features
- **Frontend**: Next.js 14 with Tailwind CSS
- **Backend**: Express.js REST API
- **Database**: PostgreSQL 15
- **Authentication**: JWT + SMS OTP
- **Localization**: English and Swahili
- **Containerization**: Docker support

### Research Ethics
- Strict 18+ age gate
- Virtual currency only (no real money)
- Clear academic purpose disclosure
- Informed consent mechanism
- Data privacy protections
